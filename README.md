# IT23818552_ITPM_Assignment1
Playwright automated tests for ITPM Assignment 1 - Singlish to Sinhala transliteration system.

Registration Number: IT23818552

Project Description

This project automates the testing of Singlish to Sinhala transliteration using Playwright.

Requirements
Python 3.11 or 3.12
Playwright
Installation Steps
Install Python
Open Command Prompt
Navigate to project folder:
cd test_automation
Install dependencies:
pip install -U pip
pip install playwright openpyxl
playwright install
How to Run

Run the following command:

python test_automation.py --excel "Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator"

Output

Results will be saved in the Excel file automatically.
